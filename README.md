# Cafe Aurora

Pagina de Cafe Aurora
Este proyecto tiene como objetivo el diseño y desarrollo de una página web interactiva para el establecimiento Café Aurora, una cafetería que busca ofrecer una experiencia única a sus clientes con un ambiente cálido, productos de alta calidad y un servicio excepcional.

La página web tiene como propósito mejorar la visibilidad del negocio, facilitar la comunicación con los clientes, y optimizar el proceso de reservas y pedidos en línea. Además, ofreceremos información sobre el menú, promociones y eventos especiales.
